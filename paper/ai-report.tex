\subsection*{How AI was used}
AI assistance was used to plan the solution and the division of work, organize the manuscript, implement and verify the dynamics, search, optimization, and replay code, run the sensitivity and load calculations, generate figures, and draft and revise text. The team selected the problem, set the scope, accepted or rejected each proposal, and directed every revision. All numerical results in the paper come from the repository code and were rechecked by replay; AI-written text was reviewed against those results.

\subsection*{How this record was prepared}
The team's queries were written in Chinese. Each query below is an English translation of the exact query, kept as close to the original wording as possible. Each AI output is summarized rather than reproduced in full, and the commands, file edits, and program output produced by the tools are omitted. Names, local file paths, and account names are replaced by bracketed placeholders to keep the paper anonymous. The complete original session logs are retained by the team and can be provided on request.
