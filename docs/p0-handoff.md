## 已冻结的主情景
原点为分离质心水平投影，x沿下程方向，h为平均海平面以上的质心几何高度；速度相对地面。航迹角从水平向上计正，机轴角从+x逆时针指向鼻端；内部状态用弧度，配置用度。

主情景航迹角15°，机轴角15°，初始角速度0；角度对比取0°、15°、30°，每个角度情景初始机轴随航迹角同步。姿态误差另做±2°、角速度±1°/s单因素扰动，避免混淆航迹变化和姿态误差。

无风、静止水平甲板，甲板高度0，忽略起落架。每个独立名义情景可重新选船位；预先布船鲁棒性分析则固定主情景船位。选定船位后水平误差要求不超过5 m。不得对每条扰动轨迹事后重新选船位并宣称同船着陆成功。

## 推进剂口径
初始总质量=130 t干质量+分离推进剂；80 t只是求解初值。推进剂初始库存已包含5 t可用储备，不得再额外叠加一次。首版不可用残余取0，作为明确简化；后续若加入，单独列项。

初始推进剂=实际消耗+触地可用储备+不可用余量+超出计划储备的剩余。优化若采用最小储备约束，则“超额剩余”在求解后据实报告。燃料为甲烷，总推进剂包括甲烷和液氧。氧燃比3.5下，甲烷质量=总推进剂/4.5，液氧=3.5倍甲烷；消耗和储备采用同一配比。

## 发动机操作约定
最多3次点火，允许滑行、入段制动和末段制动，由P2决定是否需要全部阶段。点火计数按关机到开机的转换计数，初始开机算一次。零点火延迟，不设最小开/关机时长；推力与偏转速率暂不限制，即理想瞬时执行器。其含义不是速率为0。此项局限须在讨论中披露，后续可加执行器限制验证。

关机时没有主动推力力矩；首版不假定无燃料姿控器或可动翼面。姿态控制仅来自开机偏转和被动气动力。开机节流不得小于40%，不得用微小推力模拟持续悬停。

## 着陆标准与安全边界
相对甲板速度：|vx|≤1 m/s、|vh|≤2 m/s；偏离竖直≤2°；|omega|≤1°/s；保留≥5 t可用推进剂；水平误差≤5 m。接触事件按实际圆柱姿态的最低点判定。

以上均为任务容差，不是认证限值。当前没有依据充分的最大动压、载荷和热流阈值，所以采用“必须输出峰值、暂不做结构/热安全通过判定”的约定，不能编造安全保证。地球自转、曲率、Mach/Re相关系数、分布推进剂惯量、风切变和甲板运动作为P3模型误差任务保留。

## 交接给 P2 的要求
1. 读reference.json与p0-contract.json；后者是规范文件，现有动力学不会自动执行全部调度和位置约束。
2. 主情景先使用上述参考设计，报告完整初末状态、船位、各次点火与消耗。
3. 若轨迹不可行，报告具体约束与饱和情况；不得静默修改参数或放宽容差。
4. 遇到大气越界应停止并报告，不能截断密度；更高轨迹需补高层大气。
5. 全程最优解、图表与燃料答案由P2交付，P0不将局部末段算例当成全程结论。
