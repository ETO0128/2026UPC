# 球形地球修正与重新求解

当前名义模型入口 config/spherical.json，保留 config/reference.json 对应历史平面比较。结构承受能力按用户范围排除，助推器按刚体处理，继续报告飞行气动与加速度诊断。

## 状态和方程
状态为地表弧长s、径向质心高度h、局部水平速度vx、径向速度vh、总质量m、局部机轴角theta和局部俯仰角速度omega。R=6356766 m，r=R+h。s_dot=R/r*vx，vx_dot=Fx/m-vx*vh/r，vh_dot=Fh/m-g+vx²/r。

theta_dot=omega。惯性机轴角速度为omega-vx/r，气动条带的转动局部速度必须使用此值。由惯性角动量平衡可得omega_dot=M/I+Fx/(m*r)-2vx*vh/r²。该项已同时加入JS和CasADi方程。

接触事件按球心到圆柱纵向矩形截面的最短距离计算。船位为固定地表弧长坐标，速度和姿态相对于接触点的局部水平/径向方向。地球不自转，甲板静止，纬度和航向未引入。模型没有将旧船位直接增加6.09 km。

## 重优化与复算
在原P2单次点火控制上初始化球面多重打靶，目标网格0.85、0.55、0.40 s，库存依次26.114、26.051、26.038 t，均正常收敛并通过0.005/0.0025 s球面复算。最细候选再以0.00125 s复算通过。

最终结果：
- 分离推进剂26.037844 t，其中甲烷5.786188 t、液氧20.251656 t。
- 消耗20.961641 t，触地剩余5.076203 t，已经包含5 t储备要求。
- 船位284.159834 km地表弧长，触地213.015798 s。
- 位置误差0.00333 m，水平速度大小0.00514 m/s，径向下降速度1.51509 m/s。
- 局部偏离竖直0.000139°，局部俯仰角速度0.02725°/s。
- 峰值动压293.021 kPa，非重力比力7.819 g0。

与旧平面解相比，库存减少0.190268 t，船位增加5.849398 km。比较包含重新优化后的策略变化。

> P5 更新：在 0.40 s 网格上再做三轮信赖域优化（记录在 results/spherical/sensitivity/cn-1.2.json），得到 26.020、25.967、26.011 t，选最低的 25.967 t（船位 284.120 km）。spherical-report.py 现从两处历史中选最优，selected.json 和图已更新。球面敏感性、分离角和动压上限结果见 docs/p5-task-list.md。

## 验证
- 真空100 s积分的能量误差7.45e-9 J/kg，角动量相对误差6.66e-16。
- 无外力矩情况下惯性角速度保持，惯性机轴角误差5.83e-16 rad。
- 竖直与水平圆柱接触的解析极限检查通过。
- 32个状态的CasADi/JS导数最大缩放差3.98e-16。
- 旧P1验证通过，几何开关缺省时沿用原模型行为。
- 0.0025到0.00125 s，消耗差约0.00974 kg，触地速度差约0.00016 m/s。

## 复现
使用requirements-p2.txt和P1绘图依赖，从仓库根目录执行：

```powershell
node src/verify-spherical.mjs
python src/verify-spherical-symbolic.py
python src/spherical-optimize.py
python src/spherical-report.py
```

首次求解依次执行三档网格。已有历史时从末次节点继续0.40 s网格。结果保留在results/spherical/，selected.json包含候选节点、0.00125 s复算及轨迹样本。主稿引用paper/spherical-model.tex与paper/spherical-results.tex。

当前范围继续包括有效推进参数、常系数气动、简化惯量与理想执行器。上述数值是已接受局部解，缺少全局最优证明。
