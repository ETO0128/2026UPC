# P3 第一轮控制修正

本轮沿用 P0-v1 的动力学、发动机能力和触舰标准。目标船位固定在下游 278.3104366 km。统一采用 30 t 分离推进剂，其中触舰时仍须保留至少 5 t 可用储备。30 t 是本轮选用的试算装载量，比 P2 主情景的 26.228 t 增加约 3.772 t。

## 调整与实施

1. 分离时使用测得的初始姿态、转速和恒定风估计，预测无动力下降到 25 km 的状态。
2. 以这段预测为起点，重新选择余下滑行时间、点火时刻、节流和喷口偏转，目标固定在原船位。优化固定初始质量，并保留原来的触舰速度、姿态、角速度和储备要求。
3. 在分离后的滑行期间完成规划。整条指令从分离点重新执行，分别用 0.005 s 和 0.0025 s 步长检查第一接触事件及各项触舰约束。

直接跟随省油轨迹的反馈初稿仍有末段速度和转速超限，因此本轮采用根据分离时已知条件重规划的方案。规划中用原动力学实际积分得到的滑行段作为初始猜测，并保持箭体整圈旋转的角度分支连续，避免把相同朝向错误接成额外的一整圈旋转。

## 已得到的结果

主情景、四个小扰动和六个较大扰动共 11 个算例，在两档步长下均满足 P0 触舰标准。所有新方案都使用同一个原船位和 30 t 初始库存。

| 情景 | 触舰可用推进剂 / t | 完整轨迹复算 |
|---|---:|---|
| 主情景 | 7.882 | 通过 |
| 风 −1 m/s | 7.939 | 通过 |
| 风 +1 m/s | 7.793 | 通过 |
| 初始俯仰 −0.1° | 7.866 | 通过 |
| 初始俯仰 +0.1° | 7.861 | 通过 |
| 风 −10 m/s | 8.497 | 通过 |
| 风 +10 m/s | 7.165 | 通过 |
| 初始俯仰 −2° | 7.951 | 通过 |
| 初始俯仰 +2° | 7.809 | 通过 |
| 初始转速 −1°/s | 7.434 | 通过 |
| 初始转速 +1°/s | 7.551 | 通过 |

表中采用 0.0025 s 完整复算结果。各情景的最大落点误差约 0.026 m，最大触舰下降速度约 1.584 m/s。实际消耗约为 21.503–22.835 t。风为沿航向的定常水平风，俯仰扰动只改变机轴方向，初始速度方向维持 15°。

同样装载 30 t 而沿用原 P2 指令的对照，在这 11 个情景中均未满足全部触舰条件。增加装载量与重新规划需要一起评价。

本机记录的规划耗时约为 14–43 s，首次点火在分离后约 173–176 s。规划从分离时开始，为本轮计算留出了时间余量。这是该运行环境下的实测耗时。

## 适用条件与后续工作

本轮规划使用准确已知的分离初态、恒定风和同一套动力学。每种已知情景分别计算一套指令，再执行至触舰。后续工作需要处理以下具体问题。

- 分离后新出现的阵风、测量误差及模型偏差，需要在飞行中继续估计并更新轨迹。
- 目前的情景每次只改一个输入。多项误差同时出现时的共同可行范围需要单独求解。
- 30 t 是选定的共同试算库存。进一步降低共同库存，需要重新规划并计算完整轨迹。
- 当前执行器采用瞬时响应。推力与喷口偏转速率、启动延迟、传感延迟和计算超时后的处置需要加入控制设计。
- 当前约 278 km 航程使用二维局部平面。地球曲率、自转和三维运动对末端位置的影响需要继续计算。
- 峰值动压和非重力加速度已有记录。受热模型、结构允许值和热允许值仍需明确，才能评估整段回收的安全性。

英文正文第 7 节已纳入本轮修正和适用条件。全文摘要与结论仍处于分段完善阶段。

后续的[风估计误差分析](p3-wind-estimation.md)固定本轮主情景指令，检查实际风速与规划风速不一致的影响。试过的 ±0.05 m/s 误差通过，±0.1 m/s 误差出现触舰失败或指令窗口结束。持续状态修正由此成为下一步控制工作的重点。

## 复现

使用仓库的 `requirements-p2.txt` 安装依赖。在仓库根目录运行以下命令，生成主情景的修正轨迹，再重放所有已经保存的修正轨迹。

```powershell
python src/p3-replan.py --case nominal
python src/p3-replan.py --replay-all
```

`--case` 支持 `wind-minus`、`wind-plus`、`pitch-minus`、`pitch-plus`、`wind-large-minus`、`wind-large-plus`、`pitch-large-minus`、`pitch-large-plus`、`rate-minus`、`rate-plus`。每次规划从原 P2 解重新构造初始猜测。

[逐情景规划记录与完整复算](../results/p3/replanned/summary.json)保存了各项触舰判定、最终状态、各段消耗及对照结果。相邻的逐情景 JSON 保存了可重新执行的控制节点、滑行预测和求解状态。
