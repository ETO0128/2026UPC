# P2 着陆策略与推进剂优化

## P0-v1 结果

当前参数来自 [P0 交接](p0-handoff.md)，状态、气动力、俯仰和接触几何来自 [P1 模型](planar-model.md)。以下推进剂质量均为分离时的液氧与甲烷合计，并已计入 5 t 计划储备。模型采用 2.846 MN 最大推力、40% 最低节流、330 s 比冲、10° 偏转上限和 3.5 的液氧／甲烷质量比。原先临时质点模型的 `src/p2.py`、`src/p2_scenario.json` 和 `results/p2/` 仅供历史对照。

单次点火是主情景中找到的最低已验证装载量。两次点火的优化支路把首次燃烧压到 0.001 s 的数值时长下限，总装载量仍高约 1.38 t。这个支路的首段耗量约 0.36 kg，工程意义有限。另有一条真正持续 1.5 s 的入段燃烧反馈解通过复算，需装载 38.65 t。上述对照支持用单次点火作为名义方案。推进剂数值受局部搜索、假设的瞬时执行器和姿态相关阻力模型影响。

### 初始方向对比

每个独立情景重新选择船位，随后固定该船位复算。结果用于比较初始方向，不能用于判断同一艘预先定位的船能否接住其他轨迹。

| 航迹角 | 找到的可行策略 | 分离推进剂（t） | 船位（下游 km） |
|---|---|---:|---:|
| 0° | 单次末段点火 | 24.710 | 195.999 |
| 15° | 单次末段点火 | 26.228 | 278.310 |
| 30° | 分离即点火压低顶点，再末段点火 | 67.000 | 260.001 |

30° 情景按无动力滑行会在分离后约 21.98 s 越过 P1 大气范围。可行反馈轨迹在分离时即点火，约 32.13 s 后关机，顶点为 85.90 km。计算遇越界即拒绝。更省的 30° 配点和打靶候选未通过 P1 的大气范围或触舰检查，因此 67.00 t 是已验证的策略上界。

## 求解、复算与适用范围

1. 在原版 P1 的七状态方程上扫描初始推进剂、点火高度、俯仰目标偏置和末段下沉速度参数。主情景找到 39.40 t 的单次点火参考解和 38.65 t 的两次点火参考解。低推力不被用来模拟关机。
2. 用反馈轨迹初始化 Hermite–Simpson 多阶段配点，再用每个控制区间 8 个 RK4 子步的多重打靶修正。目标为最小分离推进剂，优化阶段时长与推力控制。打靶使用局部时长和姿态范围。端点使用 P0 容差内的目标和 75 kg 数值储备裕度。候选来自局部非线性求解。
3. 将分段线性的节流和偏转节点导回原版 JavaScript P1，分别用 0.01 s、0.005 s 步长，从分离积分到箭体最先接触甲板。显式检查速度、姿态、角速度、船位、储备和点火数。对优化用的符号方程与原 P1 做了 32 个状态导数抽样比对。正式主解从 0.85 s 到 0.55 s 的打靶网格变化约 70 kg。固定主解后，复算步长从 0.01 s 降至 0.005 s，耗量变化为 0.72 kg。再降至 0.0025 s 仍通过触舰约束，耗量变化为 0.15 kg。
4. 主解最大马赫数约 5.81，动压约 297 kPa，合成非重力加速度约 7.70 g。P0 未采用结构或热流通过阈值。当前通过的范围是 P0 触舰约束，热、结构、执行机构、风和固定船位扰动属于后续验证。尤其应核查大迎角的气动载荷、箭体俯仰摆动、实际推力偏转速率和约 278 km 航程下的平面近似。

## 复现

在仓库根目录使用 Node.js 24.15、Python 3.12 和 [P2 依赖](../requirements-p2.txt)。安装依赖后按顺序运行。

```powershell
python -m pip install -r requirements-p2.txt
node src/p2-search.mjs
foreach ($strategy in @('single', 'double', 'level')) {
    python src/p2-collocate.py $strategy
    python src/p2-collocate.py $strategy --resume --shooting-step 0.85 --max-iter 280
    python src/p2-collocate.py $strategy --resume --shooting-step 0.55 --max-iter 300
}
python src/p2-collocate.py steep --steps 1.2 --shooting-step 0.85 --max-iter 260
python src/p2-collocate.py steep --resume --shooting-step 0.55 --atmosphere-buffer-m 75 --max-iter 300
python src/p2-collocate.py steep --resume --shooting-step 0.40 --rk-substeps 12 --atmosphere-buffer-m 75 --max-iter 300
python src/p2-report.py
```
