# 全程安全分析实施计划

**目标：** 按已批准的顺序，先完成全程安全分析小节；本轮不更改着陆控制，不展开下一组燃料参数情景。

**采用方案：** 读取已交付的 P2 名义解和 P3 五个持续反馈算例，沿完整下降过程提取动压、比力、机身轴向/法向气动力、力矩与来流动能通量。维持现有物理参数和 20 ms 反馈周期。原始量与论文图表来自同一计算记录。

**取舍：** 直接宣布安全缺少结构和材料依据；套用高焓钝头驻点传热式需要补充几何与适用域论证。因此本轮报告受力需求和来流能量指标，明确不将动能通量当作壁面热流，不任意设置通过阈值。下一轮再按已定情景研究燃料需求。

**文件：** `src/p3-exposure.mjs` 负责量的定义与记录；现有复算增加可选观察回调，反馈程序增加暴露量输出模式；`src/plot-p3-exposure.py` 负责图；`results/p3/safety/` 保存汇总及名义时序；`paper/p3-safety.tex` 写本轮新增正文；`docs/p3-flight-safety.md` 给出中文交接。
