# A 题论文架构

英文正文入口：`paper/main.tex`。沿用去年论文的主线，将原先两种火炮求解方法章节替换为着陆策略、推进剂估算及敏感性分析。

| 章节 | 本文内容与预期产物 |
|---|---|
| Summary | 最后撰写：模型、策略、分离推进剂质量、区间与安全条件 |
| 1 Introduction | 背景、题意重述、已知参数与目标 |
| 2 Assumptions | 各项假设的理由、范围和影响 |
| 3 Notations | 统一符号和 SI 单位 |
| 4 Model Force Analysis | 重力、大气、阻力、发动机推力和耗质 |
| 5 Model Motion Analysis | 变质量运动方程、初末条件、分段下降及数值轨迹 |
| 6 Landing Strategy and Propellant Estimation | 基准估算、点火控制、优化、推进剂预算 |
| 7 Sensitivity and Uncertainty Analysis | 初始方向、发动机、气动、风及安全储备的影响 |
| 8 Model Evaluation | 模型比较、守恒和收敛验证、优缺点与误差来源 |
| 9 Further Discussion | 姿态稳定、结构热约束、船位和海况、结论 |
| 10 Report on the Use of AI | 按实际使用记录和赛事要求披露 |
| References / Appendices | 参数来源、推导、复现说明和代码 |

## 写作与计算约定

- 初始速度只有大小，没有方向；必须指定参考情景并分析其影响。
- 船位可选不代表无需消除水平着陆速度。
- 估算应区分液氧与甲烷总推进剂质量、甲烷燃料质量、储备和不可用余量。
- 平动轨迹不能独立证明垂直姿态安全，应提供姿态控制论证或说明模型边界。
- 参数须标注题目给定、来源或建模假设；当前不填未经计算的数值结论。
- 预期图表：受力与阶段示意、轨迹、速度/高度/质量/推力时序、推进剂预算、敏感性与收敛表。
