# P3 收尾：两档横流阻力对比

本轮只改变原 P0 清单中的横流阻力系数：偏低 0.8、基准 1.2、偏高 1.6。轴向系数保持 0.8，其他参数不变。选择横流是因为现有受力分析显示，箭体侧向气动力是全程载荷的重要贡献。

各档在规划时已知，允许分别选择船位，再固定所选船位复算。从原 P2 名义解出发，用相同的单次点火局部方法重新安排库存、时长和控制，单次求解上限 140 s。本轮没有为获得全部通过而追加新方法或更多情景。

## 实际结果

| 横流系数 | 结果 | 可报告的分离总推进剂 / t | 触舰保留 / t |
|---|---|---:|---:|
| 0.8 | 求解达到时限，未获得通过候选 | — | — |
| 1.2 | 原基准通过 | 26.228 | 5.078 |
| 1.6 | 新的局部候选通过 | 27.130 | 5.072 |

“通过”要求正常收敛，并在 0.005、0.0025 s 两档从分离至触舰的完整执行中满足原 P0 条件；没有放宽容差。数值取较细一步。

偏高系数 1.6 的结果：

- 总推进剂 27.1296 t，其中消耗 22.0572 t，保留 5.0724 t；甲烷装载 6.0288 t、液氧 21.1008 t。
- 比基准多装约 0.9015 t，即 3.44%。
- 点火为分离后 174.138 s，质心高度 7.551 km，船位为下程 278.090 km。
- 触舰落点误差约 0.0214 m，下降速度约 1.468 m/s，俯仰转速约 0.0593°/s。
- 峰值动压约 297.067 kPa，峰值非重力比力约 7.187 g₀；后者低于基准的 7.703 g₀。

这条局部方案体现了一个取舍：峰值比力降低，但装载量增加。横流系数同时改变减速、俯仰力矩和转动阻尼，不能仅根据“阻力更大”推断燃料必定更少；当前比较也不足以证明全局最优装载的单调关系。

偏低系数 0.8 的求解达到约 140 s 时限，没有收敛。最后一个候选在完整执行时到达甲板平面，但相对其候选目标偏差约 147.4 m，下降速度约 14.95 m/s，偏离竖直约 33.74°，两档步长均不满足触舰条件。

因此，**不把该候选的试算装载写作燃料需求，不称其为可行上界，也不把局部搜索失败说成物理上无法着陆。** 这档仍未得到可用的重新规划结果。本轮如实保留这个限制，不继续扩展求解。

## 结论边界

本轮得到一条新增可行局部设计和一个尚未解决的阻力情景，没有建立整个 0.8–1.6 区间的燃料需求范围，更没有证明当前反馈能应对未知气动误差。该组与发动机效率组也不能直接组合为联合误差结论。结构、热和执行器局限沿用 [P3 收尾交接](p3-closeout.md)。

## 文件与复现

按现有 `requirements-p2.txt` 安装依赖，在仓库根目录运行：

```powershell
python src/p3-drag.py --cd 1.2
python src/p3-drag.py --cd 0.8
python src/p3-drag.py --cd 1.6
```

`results/p3/drag/cd-*.json` 同时保存通过和未通过候选、求解状态与完整执行记录；`summary.json` 仅为接受的候选报告装载量。受限求解的中间状态可能因机器和时间限额而变化，因此未收敛候选的诊断数值对应本轮保存的记录。英文部分见 `paper/p3-drag.tex`。
