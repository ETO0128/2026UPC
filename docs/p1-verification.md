# P1 验证与交付说明

P1完成范围：参考模型推导、解析基准、内部一致性检查、时间步长/条带数/触地事件收敛、局部有动力制动与俯仰扰动算例。P2全程轨迹、最小推进剂和固定船位捕获不在本轮范围。

## 复现
1. `node src/verify-p1.mjs`（验证通过才写结果；无第三方JS依赖）。
2. 安装Python的matplotlib、numpy；`python src/plot-p1.py`。
3. 从仓库根目录执行 `pdflatex -interaction=nonstopmode -halt-on-error -output-directory=paper/build paper/p1-report.tex` 两次。
4. 全文仍使用 paper/main.tex；P1通过input引入，不替换P2章节。

验证记录：results/p1-verification.json；局部时序：results/p1-verification-series.json。核心推导：paper/p1-model.tex；验证正文：paper/p1-verification.tex。所有图由保存的结果生成，未手工调整数据。

## 检查范围
- 标准大气五个层基准，覆盖压力/温度和越界拒绝。
- 真空竖直能量、无动力质量、无力矩转动。
- 恒推力线性耗质与水平理想火箭方程（竖直重力仍保留，不影响水平解析式）。
- 轴向/横流解析力、压心力矩、均匀风非零力矩。
- 中心纯转动气动力矩的解析积分，以及10—160条带收敛。
- 平滑四秒动力学的步长比较，以0.00125 s同方程积分为参考，非独立飞行验证。
- 0.08—0.005 s末段触地与消耗比较；姿态扰动恢复；干质量保护。

20条带在纯转动极限下的力矩误差是0.5%。最终两档局部末段消耗相差约0.00384 kg；这是该算例数值差异，不是全程精度或真实燃料不确定性。

## 重要边界
当前触地定位是线性插值，不能宣称整体四阶事件精度；耗尽事件是提前保守停止，不求精确耗尽时刻。局部速度/姿态检查不含固定船位捕获：扰动算例漂移16.56 m，超过以x=0为船位时的5 m容差。现有函数passesChosenTouchdownCriteria仍是速度/姿态/储备诊断，不能用其名称替代完整P0约束。无真实飞行数据验证，不证明热/结构安全。

论文应报告上述边界，而不把未完成的P2结果写为P1结论。零风常系数假设、等效压心、集中推进剂惯量和瞬时执行器仍须后续敏感性分析。
