# 参考参数与平面刚体模型 v1

## 参数采用声明（可用于论文）
根据标准大气、圆柱横流研究和液氧/甲烷推进资料，本研究构建一套参考助推器设计，而不声称识别题目未指定的实际发动机。采用标准大气1976；借鉴 BE-4 公开推力量级，将着陆发动机组最大推力设为2.846 MN。有效比冲取330 s，氧燃比取3.5，最低节流比取40%，最大偏转角取10°。后四项是为封闭模型作出的设计假设，其中氧燃比参照 NASA 19950021840 的甲烷/氧设计讨论；均不表述为本题发动机实测值。

轴向阻力系数取0.8，横流系数取1.2，压心等效偏置取+0.05L（朝鼻端）；这些是参考圆柱气动问题后选定的工程闭合参数，并非从NACA报告图线读取的值。首版取常数，不宣称已经包含Mach/Re依赖。采用80 t试算推进剂，初始航迹角和机轴角均为向上15°，初始角速度为0。所有参数集中于 config/reference.json。80 t不是计算所得最小燃料量。

## 状态、坐标与惯量
状态 y=(x,h,vx,vh,m,theta,omega)。theta 为机轴从水平朝鼻端的逆时针角，竖直向上为π/2。e=(cos theta,sin theta)，n=(-sin theta,cos theta)。

干体按均匀圆柱，I_d=m_d(3R²+L²)/12。首版将剩余推进剂集中于质心且忽略其横向惯量，故I=I_d为常数；假设排出推进剂携带质心平动但无额外绕质心角动量。这是一项显式质量分布/流出闭合，不是把变惯量问题遗漏掉。下一版应加入真实储箱分布及角动量通量，不能简单对变质量刚体套 I*omega_dot=tau。

## 分离轴向与横流气动力
相对空气速度u=v-w，u_a=u·e，u_n=u·n。

F_a=-rho C_a A_end u_a|u_a|/2，沿e方向。

将箭体分为20条等长横流条带。等效力臂s_i位于[-L/2+Δl,L/2+Δl]，局部法向速度u_ni=u_n+omega*s_i。

F_ni=-rho C_n D Δs u_ni|u_ni|/2，沿n方向。

总力F=F_a e+sum(F_ni)n，气动力矩M_a=sum(s_i F_ni)。这种分布同时给出静态压心偏置效应和旋转阻尼，不另外叠加同一阻尼项。等效条带平移是压心不确定性的低阶代理，不是精确表面网格；轴向力取机轴中心线作用，无轴向力矩。

该模型在纯轴向与纯横流极限分别还原端面与侧面阻力；保留横流法向力，避免把任意迎角气动力全部强制沿速度。没有环境风时也有相对气流与力矩；均匀风不消除力矩。

## 推进与俯仰方程
T=Tmax*u_T，开机时0.4≤u_T≤1，关机时T=0；偏转角|delta|≤10°。

m_dot=-T/(g0 Isp)

v_dot=g(h)+[F+T(cos(theta+delta),sin(theta+delta))]/m

theta_dot=omega

I_d omega_dot=M_a-(L/2)T sin(delta)

推力作用点在尾端。正偏转产生负俯仰力矩；代码已检查符号。未加入独立、无需燃料的神奇姿态执行器：关机时推力控制力矩为0。当前尚未建模偏转执行机构速率、关机时姿控推进器和可动翼面。

## 触地及运行
接触条件使用圆柱几何：h-deck = (L/2)|sin theta|+(D/2)|cos theta|；忽略起落架，甲板水平静止。按实际姿态判断最先接触，而不是始终把质心高度32.5 m当触地。

运行 `node src/run-planar.mjs`。输出 results/planar-summary.json 和 results/planar-trajectory.json。状态顺序同上；采样记录控制量便于复算。

已验证：轴向/横流阻力符号、转动阻尼、推力偏转力矩符号、质量流率和对称无风气动耗散。0.02/0.01 s两档步长对末段算例作初步比较。局部末段算例从1200 m、竖直速度-90 m/s、质量180 t、竖直且无角速度起步，触地竖直速度约-1.503 m/s，消耗约22.679 t。它只检验有动力制动实现，不代表全程需求或姿态扰动鲁棒性。

全程演示使用15°分离、80 t试算推进剂、15 km以下全推力扶正制动，未通过触地约束。其失败结果保留，不用于推荐燃料量。下一步应优化初始机轴情景、入段燃烧、点火时刻、推力及姿态指令，并验证非零初始角度/角速度扰动。

尚需量化的限制：马赫数/雷诺数相关系数、热流与结构阈值、地球曲率及自转、风切变、质心迁移、执行器速率和重启限制。当前 passesChosenTouchdownCriteria 仅表示速度/姿态/储备满足选定容差，不等同完整工程安全认证。
